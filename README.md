Wavelet-Based Signal Processing Using MATLAB

This repository contains the MATLAB App Designer implementation developed for the MSc project Wavelet-Based Denoising and Compression of Non-Stationary Signals Using MATLAB.

The application provides an interactive environment for analysing non-stationary signals using wavelet-based techniques. The implemented system supports Discrete Wavelet Transform (DWT), Inverse Discrete Wavelet Transform (IDWT), wavelet-based denoising, coefficient-based compression and Continuous Wavelet Transform (CWT) time-frequency analysis.

Input Signals: Noisy Sine, Speech and ECG.

Wavelet Configurations: Haar, db2, db4, db8, sym4 and coif1.

Performance Measures: Mean Squared Error (MSE), Signal-to-Noise Ratio (SNR), compression ratio and processing time.

Software: MATLAB with Wavelet Toolbox and MATLAB App Designer.
